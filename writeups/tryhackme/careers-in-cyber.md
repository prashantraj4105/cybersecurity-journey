## Roles Covered

### 1. Security Analyst
Protects the company by constructing security measures and analyzing threats.
- Analyzes security across the organization
- Documents network safety reports and issues
- Develops security plans based on emerging attacks
- Works with stakeholders to understand security requirements

**THM Path:** Pre-Security → Cybersecurity 101 → SOC Level 1

### 2. Security Engineer
Builds and maintains secure systems.
- Tests and screens security measures across software
- Monitors networks and updates systems to mitigate vulnerabilities
- Identifies and implements optimal security systems

### 3. Incident Responder
Responds to breaches quickly and effectively.
- Key metrics: MTTD, MTTA, MTTR (Mean Time to Detect, Acknowledge, Recover)
- Develops actionable incident response plans
- Post-incident reporting and preparation for future attacks

### 4. Digital Forensics
Investigates digital evidence legally.
- Collects evidence following legal procedures
- Analyzes digital evidence to answer case questions
- Documents and reports findings

### 5. Malware Analyst
Analyzes malicious software.
- Static analysis — reverse engineering without running the malware
- Dynamic analysis — observing malware in controlled environment
- Documents and reports all findings

### 6. Penetration Tester
Legally attacks systems to find vulnerabilities before real attackers do.
- Tests computer systems, networks, and web applications
- Performs security assessments and audits
- Reports findings with recommendations

### 7. Red Teamer
Acts as a real adversary to test an organization's full defenses.
- Emulates threat actors — attacks, maintains access, avoids detection
- Assesses security controls, threat intelligence, incident response
- Provides actionable feedback from attacker's perspective

---

## Key Takeaway
Each role feeds into the others. As an offensive security aspirant,
understanding all roles helps you think like both attacker and defender.
